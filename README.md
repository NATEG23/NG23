# NG23 Collective Website

This version is designed for GitHub's browser uploader. Every file goes directly in the repository root, so no `assets` folder is required.

## Upload
1. In the repository, select **Add file** and then **Upload files**.
2. Upload every file from this package together.
3. Commit the files to the `main` branch.
4. In **Settings > Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`.

## Important
Keep all image, CSS, JavaScript, SVG, and HTML files in the same repository level as `index.html`.
