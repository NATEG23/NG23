# NG23 Collective Website

A static GitHub Pages-ready website for NG23.

## Files
- `index.html` - page structure and copy
- `style.css` - responsive styling
- `script.js` - mobile menu and footer year
- `assets/` - logo and uploaded photos

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select your main branch and root folder, then save.

## Edit notes
- Change text in `index.html`.
- Replace photos in `assets/` with the same filenames to avoid editing code.
- Update the contact link in the Contact Us button if needed.
